# VlessPanel — веб-приложение для управления 3X-UI панелями

## Задача приложения
	
- вывод списка клиентов с 3xui панели через API.
- создание клиентов на выбанной 3xui панели через API.
- создание подписки и редактирование готовых подписок, собранных из vless ключей.
## 
Концепция

Одностраничное веб-приложение (панель управления) для работы с 3X-UI панелями, клиентами, ключами и агрегированными подписками. Всё на одном экране, компактно, шрифт поменьше.


### Функционал

- В левой колонке для выбранной панели показываются все клиенты, каждый из которых можно раскрыть кнопкой 🔑.
- При нажатии на 🔑 раскрывается список VLESS-ключей — **по одному чипсу на каждый инбаунд**, в котором состоит клиент
- Каждый чипс подписан `{inbound}-{client} {protocol} {security} {transport}`
- В правой половине приложения - список собранных ключей-подписок. Каждый такой ключ - это текстовый файл "configs-{ClientName}.txt" в котором каждая строчка - это vless ключ. Пусты строки игнорируются.

### Бэкенд: Go
- **Фреймворк:** `net/http` + `chi` или `gin` (стандартный роутер, минимум зависимостей)
- **Данные:** JSON-файлы на диске (простота, парсинг без боли)
  - `panels.json` — список 3X-UI панелей (url, token, name)
  - {vless-aggregator-dir}/configs-{ClientName}.txt - массив файлов из папки VlessAggregator
- **3X-UI API:** прямой HTTP-вызов из бэкенда (храним токены только на сервере, не отдаём фронту)
- **VlessSubTest:** exec(`/home/klem/VlessSubTest/vlesssubtest url=...`) — стримим вывод на фронт

### Фронтенд: React
- **Сборка:** Vite (быстро, современно)
- **Стейт-менеджмент:** React Query (танчим API) или Zustand (простой)
- **UI-кит:** без библиотек — кастомный CSS Modules / Tailwind
- **Тема:** тёмная, синяя

### Доставка
- Бэкенд раздаёт статику фронта (embedded в Go бинарник или рядом)
- Единый порт (8080) — бэкенд сервит `/api/*` и статику

## REST API бэкенда

### Панели

| Метод  | Путь                                  | Описание                                  |
| ------ | ------------------------------------- | ----------------------------------------- |
| GET    | `/api/panels`                         | Список панелей                            |
| POST   | `/api/panels`                         | Добавить панель `{name, url, token}`      |
| DELETE | `/api/panels/:id`                     | Удалить панель                            |
| GET    | `/api/panels/:id/clients`             | Список клиентов панели (через 3X-UI API)  |
| POST   | `/api/panels/:id/clients`             | Создать клиента `{email, inboundId, ...}` |
| GET    | `/api/panels/:id/clients/:email/keys` | VLESS-ключи клиента                       |
| POST   | `/api/panels/:id/inbounds`            | Список инбаундов панели                   |

### Подписки (персональные сборки ключей)

**Важно:** одна подписка = **один реальный человек** (например, «ExampleClient»). Внутри подписки — VLESS-ключи этого человека с **разных 3X-UI панелей/серверов**, объединённые в одну ссылку-подписку.

| Метод  | Путь                            | Описание                                       |
| ------ | ------------------------------- | ---------------------------------------------- |
| GET    | `/api/subscriptions`            | Список подписок                                |
| POST   | `/api/subscriptions`            | Создать `{name, keys[]}` (name = имя человека) |
| GET    | `/api/subscriptions/:id`        | Детали подписки                                |
| PUT    | `/api/subscriptions/:id`        | Обновить (добавить/убрать ключи)               |
| DELETE | `/api/subscriptions/:id`        | Удалить                                        |
| GET    | `/api/subscriptions/:id/raw`    | Содержимое config-{name}.txt (сырые vless:// ключи) |
| POST   | `/api/subscriptions/:id/test`   | Запустить VlessSubTest                         |

## Тема оформления (утверждено ✅)

- **Тип:** Тёмная
- **Фон:** почти чёрный (`#0d1117` / `#0a0e1a`)
- **Текст:** белый (`#e6edf3`)
- **Акцент:** синий (`#58a6ff` — ссылки, кнопки, выделения)
- **Выделенное:** светлее невыделенного (инверсный подход)
- **Блоки:** хорошо различимые карточки / секции с тонкими границами
- **Вторичный текст:** серый (`#8b949e`)
- **Поверхности:** карты с фоном чуть светлее основного (`#161b22`)

## Создание подписок

- Каждая новая созданная подписка должна порождать новый `config-{ClientName}.txt` файл в папке VlessAggregator.
- Путь к папке агрегатора указывается в конфиге приложения (например, `.env` или простой текстовый файл). При изменении подхватывается при следующем запуске.
- Формат конфига:
  ```
  vless-aggregator-dir=/opt/VlessAggregator/
  ```
- Ключи в `config-{ClientName}.txt` хранятся в сыром виде (каждая строка — vless:// ссылка), агрегатор сам оборачивает их в base64.
- При редактировании подписки через панель приложение перезаписывает файл напрямую, рестарт агрегатора не требуется.
